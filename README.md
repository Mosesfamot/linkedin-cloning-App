# ![Checklist Icon](https://img.icons8.com/emoji/48/000000/check-mark-emoji.png "Checklist") A Responsive Linkedin Clone

A cross-pltform responsive Linkedin Clone App built using HTML, CSS and JavaScript. The website includes multiple linkedin pages including the chatbox and profile page.

---

## ![Features Icon](https://img.icons8.com/ios-filled/50/000000/list.png "Features") Features

### Core Features

- **Authentication Pages**:
  - **Login**: Secure login with validation.
  - **Signup**: User registration form with basic field validations.

- **User-Friendly Interface**:
  - Clean, responsive design with intuitive navigation.
  - Smooth transitions and animations.

---

## ![Tech Stack Icon](https://img.icons8.com/color/48/000000/system-task.png "Tech Stack") Tech Stack
- **Frontend**: HTML + CSS + JavaScript  
- **Styling**: CSS 
- **Version Control**: Git + GitHub

## ![Setup Icon](https://img.icons8.com/color/48/000000/settings.png "Setup") Installation

### Prerequisites
- Node.js (v16 or higher)
- Git

### Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/Mosesfamot/linkedin-cloning-App.git
   ```
2. Navigate to the project directory:
   ```bash
   cd linkedin-cloning-App
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   start live server
   ```
5. Open your browser and navigate to:
   ```text
   http://localhost:5500
   ```
